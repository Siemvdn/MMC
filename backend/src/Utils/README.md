# Utils

**Verantwoordelijkheid:** kleine, zelfstandige hulpmiddelen die niet bij één
laag horen.

- `Logger` — schrijft fouten naar `storage/logs/error.log`.

Deze map is geen vergaarbak. Hoort iets bij een specifieke laag, dan gaat
het dáárheen; past het nergens, dan is dat meestal een teken dat de
verantwoordelijkheid nog niet scherp is (CLAUDE.md §4).
